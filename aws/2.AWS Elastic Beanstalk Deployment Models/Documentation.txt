# AWS ELASTIC BEANSTALK DEPLOYMENT MODELS

## PROJECT 2

Project Name:
AWS Elastic Beanstalk Deployment Models

1. PROJECT SETUP

---

1. Log in to the AWS Management Console.

2. Open the AWS Elastic Beanstalk service.

3. Prepare the application files and create a ZIP package.

4. Keep the application ZIP file ready for deployment.

5. IAM ROLE CONFIGURATION

---

1. Open the IAM service.

2. Go to Roles.

3. Check the IAM roles required for the Elastic Beanstalk environment.

4. Verify that the required permissions are attached.

5. Make sure Elastic Beanstalk can use the required IAM roles
   during environment creation and application deployment.

6. CREATE ELASTIC BEANSTALK APPLICATION

---

1. Open Elastic Beanstalk.

2. Create a new application.

3. Enter the application name.

4. Select the required application platform.

5. Upload the application ZIP file.

6. Create the environment.

7. CONFIGURE ENVIRONMENT

---

Check the environment configuration after creation.

The environment can use AWS resources such as:

* EC2
* VPC
* Security Groups
* Application Load Balancer
* Auto Scaling Group
* IAM Roles

5. SINGLE INSTANCE DEPLOYMENT

---

1. Configure the environment as Single Instance.

2. Create the environment.

3. Verify that the EC2 instance is running.

4. Open the Elastic Beanstalk environment URL.

5. Verify that the application is working.

6. HIGH AVAILABILITY DEPLOYMENT

---

1. Configure the environment for High Availability.

2. Use multiple EC2 instances.

3. Configure an Application Load Balancer.

4. Configure Auto Scaling.

5. Create/update the environment.

6. Verify that the application is accessible through the
   environment URL.

7. APPLICATION TESTING

---

1. Open the Elastic Beanstalk environment.

2. Check the environment health.

3. Open the environment URL in a browser.

4. Verify that the application loads correctly.

5. Check that the required EC2 and load balancing resources
   are working correctly.

6. DEPLOYMENT POLICIES

---

Test the application deployment using the available policies:

* All at Once
* Rolling
* Rolling with Batches
* Immutable

For each deployment, verify that the new application version
is deployed successfully.

9. BLUE-GREEN DEPLOYMENT

---

1. Create the Blue environment with the current application version.

2. Create the Green environment for the new application version.

3. Deploy the new application version to the Green environment.

4. Test the Green environment.

5. Verify that the new version is working correctly.

6. Switch traffic from the Blue environment to the Green environment.

7. Verify that users are now reaching the Green environment.

8. Keep the Blue environment available temporarily for rollback
   if required.

9. FINAL VERIFICATION

---

Verify the following:

* Elastic Beanstalk environment is healthy.
* Application is accessible.
* EC2 instances are running.
* Load Balancer is working.
* Auto Scaling is configured where required.
* IAM roles and permissions are working.
* New application version is working correctly.
* Traffic is reaching the correct environment.

11. PROJECT RESULT

---

Successfully deployed and tested an application using AWS
Elastic Beanstalk.

The project covered:

* Elastic Beanstalk application deployment
* IAM role configuration
* Single Instance environment
* High Availability environment
* Deployment policies
* Blue-Green deployment
* Traffic switching
* Application testing
